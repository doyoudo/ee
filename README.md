# ee

`ee` 是一个键盘驱动的 Windows 环境变量管理器。它用 Rust 构建为单个 `ee.exe`，直接读写 Windows 注册表，不联网、不在后台运行，也不需要 PowerShell 模块。

- **用户 / 系统**：分开浏览，按名称搜索，查看、新建、修改和删除变量。
- **弹窗编辑**：在原列表上操作，取消后保留筛选和选中项。
- **`Path` 逐项编辑**：添加、删除和排序，不自动去重或展开引用。
- **按需读取**：列表只显示名称，查看或编辑时才读取值；不记录变量值到日志或配置文件。

## 快速开始

在 Windows 10/11 x64 的 Windows Terminal 或其他交互式控制台中运行，最小窗口为 48 × 12。只有 `ee.exe` 就能运行，不需要安装 Rust。已有可执行文件时，在其所在目录运行 `./ee.exe`；要从源码构建，请在克隆后的仓库根目录运行：

```powershell
./build.ps1
./target/release/ee.exe
./install.ps1                  # 可选：安装到 ~/.local/bin，不修改 PATH
```

源码构建需要 Rust stable（最低 1.88）和 Windows 链接器。默认 MSVC 工具链需要 Visual Studio Build Tools 的「使用 C++ 的桌面开发」工作负载。脚本也可复用父目录已有的 CK 本地工具链；依赖已缓存时可以加 `-Offline`。

要在任意目录运行 `ee`，请确认安装目录 `%USERPROFILE%\.local\bin` 已加入永久的用户 `Path`。可以先用完整路径启动 `ee`，在 `User` 页编辑 `Path`，把该目录作为一项加入。若新标签页仍找不到命令，请退出所有 Windows Terminal 窗口，再从开始菜单启动。用 `Get-Command ee` 核对实际路径，`ee --version` 查看版本。升级前关闭 `ee`，再运行 `./install.ps1 -Force`；卸载时删除安装目录中的 `ee.exe`，不会撤销此前保存的环境变量。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓、Home / End、PgUp / PgDn | 列表导航；查看弹窗里可滚动长值 |
| `/` 或 Ctrl+F | 进入搜索，按名称即时筛选；Enter 保留筛选，Esc 清除 |
| → / ← | 在列表上方查看选中变量 / 关闭查看弹窗 |
| Tab / R / Ctrl+R | 切换用户与系统 / 重读当前列表 / 重读两份列表（均不修改变量） |
| A / E / Del | 新建 / 编辑 / 删除；查看时也可按 E 编辑 |
| Enter | 确认筛选、进入下一字段、保存表单或确认删除 |
| Ctrl+S / Ctrl+V / Ctrl+U | 备用保存 / 从系统剪贴板粘贴 / 清空编辑框 |
| F3 | 新建时在 `REG_SZ` 和 `REG_EXPAND_SZ` 之间切换 |
| `?` / Esc / Ctrl+Q | 帮助 / 返回或清除搜索 / 退出 |

## 编辑变量与 Path

新建默认使用 `REG_SZ`，用 `Tab` 或 `↑/↓` 在名称、值和类型之间移动；停在类型行时按 `←/→` 切换，也可按 `F3`。如果要让 Windows 展开 `%VAR%` 引用，选择 `REG_EXPAND_SZ`。已有值保留原类型，不支持改名。非字符串和无法解码的字符串只读。保存空字符串与删除变量不同。

编辑已有 `Path` 会在弹窗中显示逐项列表：`A` 添加、`→` 修改、`Del` 移除、`Ctrl+↑/↓` 调整顺序。条目编辑框出现在同一个弹窗内，按 `Enter` 确认该条目，再按 `Enter` 保存到注册表；`F2` 切换逐项 / 原始文本模式，新建 `Path` 也可按 `F2`。不会去重、去引号或展开 `%VAR%`；保留分号分隔的空项。不成对的引号需要用原始文本模式处理。系统 `Path` 和用户 `Path` 分开显示，不在工具内合并。

`User` 写入 `HKCU\Environment`，通常不需要管理员权限；`System` 写入 `HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\Environment`，通常需要以管理员身份启动。保存或删除前会复核原值，发现外部修改就拒绝覆盖。请先核对作用域；工具没有撤销和历史备份。

## 什么时候生效

`R` 和 `Ctrl+R` 只从注册表重读变量名列表，用于查看其他工具新增或删除的变量；它们不写注册表、不广播通知。查看或编辑单个变量时会直接读取它的最新值。通过 ee 保存或删除后，当前列表会自动重读，不需要再按 `R`。

保存或删除会广播 Windows 环境变更通知；随后从已刷新环境的启动器（例如开始菜单）启动的新进程可读到新值。已打开的 PowerShell、其他应用和从它们启动的子进程可能仍使用旧值；不要在旧 PowerShell 里启动子进程来判断是否生效。如果启动器缓存了环境，彻底退出重开启动器，必要时注销再登录。若显示通知失败，注册表写入已经完成，无需重复保存。

## 开发与验证

```powershell
./build.ps1 -Test
cargo fmt --check
cargo clippy --all-targets --locked -- -D warnings
```

Windows CI 运行测试并构建 Release。注册表测试使用当前用户下的临时测试键，不修改真实环境变量。要手动验证生效，可在测试账户中用 ee 新建唯一的用户变量，例如 `EE_SMOKE_2026`，值为 `ee-test`；保存后从开始菜单新开 PowerShell，运行 `$env:EE_SMOKE_2026`，对比原窗口，再用 ee 删除。系统写权限请在隔离环境测试。

在一台 Windows x64 / ConPTY 环境中的 Release 实测：`ee.exe` 约 361 KiB，空闲工作集约 5.7 MiB、私有提交约 1.1 MiB。数值不包含宿主终端，因机器而异；退出后无常驻进程。
